# AtDev Billing — Hybrid plans (DistroBoxer)

**Status:** proposal only. The open-source project and local system-management functionality remain free.

## Hybrid model

Do not charge for local use, core container/distro workflows, or access to user-owned system resources. Possible future paid offerings are limited to optional hosted team management, managed images, or support if those services are implemented and safely operated.

## Proposed tiers (CLP/month; exploratory)

| Plan | Reference price | Scope |
| --- | ---: | --- |
| Community | $0 | Local and self-hosted use |
| Supporter | Voluntary | Optional development contribution |
| Team | $1,990 | Future hosted team conveniences, only after implementation |

Never make local recovery or essential security functions subscription-dependent. Hosted services require explicit consent, least-privilege access, and data export/deletion.

No checkout is active. Prices are placeholders; review costs and legal/payment requirements with an adult account owner before launch.
