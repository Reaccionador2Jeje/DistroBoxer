DistroBoxer is an open-source Linux distribution environment manager.

The project is built around a shared Rust engine, with a native Android application and a desktop application for Windows and Linux.

Planned capabilities:
- Browse supported Linux distributions.
- Download and verify trusted root filesystem archives.
- Keep each distribution isolated in app-private storage.
- Manage long-running downloads with progress notifications.
- Launch Linux userspace environments through a compatible unprivileged runtime.

DistroBoxer does not require Android root access. A userspace runtime such as PRoot does not provide a separate Linux kernel.

This is an early development build. An Alpine Linux 3.24.4 rootfs installation preview is available on ARM64 and x86_64. Other distributions are currently catalog profiles only. Interactive Linux terminal execution is still under development.
