DistroBoxer is an open-source Linux userspace environment manager.

Features in this development preview:
- Browse eight Linux distribution profiles.
- Install Alpine from its official minirootfs archive.
- Install Debian, Ubuntu, Arch Linux, Fedora, openSUSE Tumbleweed, Void Linux, and Kali Linux from official OCI container images.
- Verify OCI manifest and layer SHA-256 digests before applying image layers.
- Keep each root filesystem isolated in app-private storage.
- Track background downloads and installation progress.
- Run supported Linux userspace environments through an unprivileged runtime.

DistroBoxer does not require Android root access. PRoot is a userspace compatibility layer and does not provide a separate Linux kernel. OCI images are container base root filesystems, not bootable virtual machines.

Architecture support depends on each upstream image. The official Arch Linux OCI image currently supports x86_64 only; the other OCI profiles target ARM64 and x86_64. Kali's official rolling container image is a minimal base and does not include its default metapackage.

This is an early development build. Automated registry integration tests and physical-device installation validation are still in progress. Interactive Linux runtime compatibility may vary by distribution and device.
